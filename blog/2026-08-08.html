Fast Days

Today went by so fast. I'm grateful to my past self (yesterday) for setting aside some stress and setting me up for success today.

I started out with a For Loop Yourself plan, which I talk about in my randomizing decisions trinket. I looped between 3 things - learn a page/lesson/section from some technology, then do one Japanese practice schedule, then sort out one note from my Notes app. I interspersed it with a reset task every 3 hours, which meant that I also got groceries, meditated, exercized, and I'm about to watch a movie.

I'm not sure how it's already evening, I feel like it should only be noon! Fast days like this are the best, I just wish they would last longer. They're indicative that I found a flow state for a large portion of my day.

More days like this in the future, please!
